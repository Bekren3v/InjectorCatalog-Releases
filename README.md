# Injector Catalog Stable

**Каталог бензиновых форсунок и журнал испытаний на стенде для автосервиса.**

Программа помогает собирать собственную базу форсунок, сохранять результаты проверок и готовить отчёты для клиентов. Сделана для повседневной работы диагноста: найти форсунку по номеру, посмотреть применяемость, внести замеры и распечатать результат.

[**Скачать последнюю опубликованную версию для Windows**](https://github.com/Bekren3v/InjectorCatalog-Releases/releases/latest)

Программа распространяется бесплатно для тестирования. Этот репозиторий содержит установщики и описания версий.

## Что умеет

- **Каталог форсунок.** Поиск по OEM, автомобилю, мотору и кузову. Карточки с фотографиями, заметками, параметрами, источниками и статусом достоверности сведений.
- **Свои марки и записи.** Добавление и редактирование форсунок, добавление и переименование марок автомобилей. Марка автомобиля и изготовитель форсунки задаются отдельно.
- **Применяемость и связи.** Автомобили, двигатели, схемы узлов, уплотнения и связанные модели форсунок. В связях можно указывать ограничения и предупреждения о невзаимозаменяемости.
- **История испытаний.** Добавление, изменение и удаление проливок с датой и временем, стендом, давлением и режимом проверки. Замеры по каждой форсунке, сопротивление, герметичность, примечания и вложения с фото и видео.
- **Калькулятор и сравнение.** Расчёт отклонений налива, сравнение результатов до и после ручной чистки. Работа со своими эталонами и нормами из мануалов с указанием источника и условий проверки.
- **Отчёты и документы.** Предварительный просмотр, печать, PDF, экспорт документов в Word и Excel. Заказ-наряды, акты, собственные шаблоны услуг и локальный прайс.
- **Резервные копии.** Сохранение базы и вложений в ZIP и восстановление из копии для переноса на другой компьютер.

## Для кого и как использовать

Для диагностов, автоэлектриков и мастеров, которые проверяют бензиновые MPI и DI/GDI-форсунки на стенде и хотят хранить результаты в одном месте.

Обычный порядок работы:

1. Найти форсунку в каталоге или добавить новую.
2. Указать применяемость, параметры и источник сведений.
3. Добавить проливку: дату, оборудование, режим и результаты по форсункам.
4. Сравнить замеры, при необходимости повторить проверку после обслуживания.
5. Подготовить отчёт для клиента и сохранить резервную копию базы.

Основные функции работают локально без подключения к интернету. Для открытия внешних источников нужен интернет.

## Установка

1. Откройте [последний релиз](https://github.com/Bekren3v/InjectorCatalog-Releases/releases/latest).
2. В разделе **Assets** скачайте файл `InjectorCatalog_Stable_..._Setup.exe`.
3. Запустите установщик и следуйте его шагам.

Отдельно устанавливать Python не нужно. Архивы **Source code (zip / tar.gz)**, которые GitHub добавляет автоматически, не являются дистрибутивом приложения.

## Обновление и сохранность базы

Перед обновлением сохраните ZIP базы через меню программы и закройте приложение. Новый установщик запускайте поверх прежней версии **в ту же папку**.

Папка установки по умолчанию:

```text
%LOCALAPPDATA%\Programs\InjectorCatalogStable
```

Папка вашей базы и вложений:

```text
%LOCALAPPDATA%\Programs\InjectorCatalogStable\data
```

Чтобы открыть папку, вставьте путь в адресную строку Проводника и нажмите Enter. Если при установке выбрана другая папка, база находится в подпапке `data` внутри неё.

**Не удаляйте и не заменяйте папку `data` при обновлении.** Публикуемые установщики не содержат рабочую пользовательскую базу.

Для переноса на другой компьютер используйте полный резервный ZIP. Его можно хранить на внешнем носителе или в своей синхронизируемой облачной папке. Прямой отправки в Яндекс Диск или на почту в программе нет.

## О справочных значениях

Программа не является официальным каталогом автопроизводителей. Часть сведений требует проверки; учитывайте источник и статус достоверности записи.

Нормы зависят от конкретной форсунки, оборудования и процедуры. Давление, длительность импульса, число циклов и другие условия важны для сравнения. Собственный эталон со стенда не становится заводским допуском. Расчёт отклонений сам по себе не заменяет заключение специалиста.
